# my portfolio

my personal website, built with html and tailwind.

## what's on it

- a bit about me and what i like
- links to my other stuff

## tech

- plain html
- [tailwind css](https://tailwindcss.com) via cdn (no build step)

## run it locally

just open `index.html` in your browser.

or serve it:

```bash
npx serve .
```

## structure

```
web-hack_club/
├── index.html
├── hero.jpg
├── images.jpeg
└── README.md
```

## deploy

it's a static site, so anything works: GitHub Pages, Netlify, Vercel, or Cloudflare Pages. point it at the repo root and you're done.
